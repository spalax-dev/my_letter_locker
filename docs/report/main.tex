\addcontentsline{toc}{section}{Introducción}

\noindent En el presente documento se especifica el proceso de desarrollo de \emph{My Letter Locker}\footnote{Proyecto final para la asignatura Teoría de Lenguajes Formales de la Universidad del Quindío}, una página web que permite crear y compartir cartas digitales cifradas. En un contexto donde la privacidad de la comunicación digital es una necesidad creciente, esta aplicación busca garantizar que solo el remitente y el destinatario puedan acceder al contenido de las cartas mediante cifrado. Desde la perspectiva de los lenguajes formales, el proyecto implementa expresiones regulares y autómatas para validar patrones en los textos (titulo, correos, URLs, fechas, etc.) y verificar las entradas del usuario de forma interactiva.
