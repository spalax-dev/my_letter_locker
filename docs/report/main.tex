\addcontentsline{toc}{section}{Introducción}

\noindent La Teoría de Lenguajes Formales proporciona los fundamentos matemáticos para el procesamiento automático de texto y el análisis sintáctico. Entre sus herramientas principales se encuentran las expresiones regulares, que permiten definir patrones mediante una notación declarativa para la búsqueda y validación de cadenas con estructura formal (correos electrónicos, URLs, fechas, etc); y los autómatas finitos, modelos abstractos compuestos por estados y transiciones que procesan secuencias de entrada símbolo a símbolo, resultando adecuados para reconocer lenguajes con estructura jerárquica como los comandos de personalización de una aplicación.
El presente proyecto, desarrollado como trabajo final de la asignatura Teoría de Lenguajes Formales de la Universidad del Quindío, aplica estos conceptos al desarrollo de \emph{My Letter Locker}, una aplicación web para compartir cartas digitales de forma privada.

% ==================================
\section{Definición y requisitos del proyecto}
\emph{My Letter Locker} es una aplicación web que permite compartir cartas digitales de forma privada, sin necesidad de registro ni almacenamiento en servidor. El contenido de cada carta se cifra mediante un algoritmo de cifrado simétrico y se embebe directamente en la URL, de manera que solo quien posea el enlace y la palabra secreta puede descifrar su contenido.

Para procesar las entradas del usuario al momento de redación de la carta, se aplican técnicas de la Teoría de Lenguajes Formales que permiten reconocer dos tipos de patrones. Por un lado, las expresiones regulares definen patrones para identificar datos estructurados, como direcciones de correo, URLs o fechas. Por otro lado, los autómatas finitos modelan y reconocen patrones de comandos propios del sistema, los cuales modifican la apariencia del texto y el entorno visual de la aplicación.
