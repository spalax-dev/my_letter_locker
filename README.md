# My Letter Locker

Create a private letter that only your recipient can open. Encrypt your message, share a single URL, and let them unlock it with their secret word. No sign-ups, no databases — just a link.


## Why Letter Locker?

- No storage - messages live only in URLs
- Password protection - secret word required
- Works everywhere - any device, any messenger
- Instant - create and share in seconds
- One-time use ready - read once and discard
